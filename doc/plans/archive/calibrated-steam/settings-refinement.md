# Calibration settings refinement

Persist the planned milk quantity independently from actual measured milk. Store an
optional milk-temperature target in Celsius as a note only, without changing steam
commands, the timer formula, or heater settings. All readings in a calibration set
should share that target and similar starting conditions.

Open complete saved calibrations as compact summaries. Edit opens the selected
reading for manual or guided entry; accepting an edited reading returns to review
when the set is complete. Draft values still require Save calibration.

Explain the empty starting-pitcher selection, retain the first configured choice,
and preserve later user choices. Add Instructions and Glossary tabs alongside the
existing settings tabs, keeping configured-pitcher badges intact.

Verify real generated-page behavior with the existing DOM harness, persistence
across page reloads, target/measured separation, guided flow preparation, and
unchanged calculation results. Regenerate bundled assets and run plugin tests.
